تقدم التصميم: سياسة الاستجابة ودفاتر العمل المؤتمتة

Response Policy Layer

طبقة سياسة الاستجابة

The policy layer maps the prioritized risk score and confidence indicator to a specific playbook. A confidence gate ensures high-impact response actions are only triggered when the model's confidence exceeds a defined threshold — otherwise routing to analyst approval.

تربط طبقة السياسة درجة المخاطر المُرتبة ومؤشر الثقة بدفتر عمل محدد. بوابة الثقة تضمن أن إجراءات الاستجابة عالية التأثير لا تُطلق إلا عند تجاوز عتبة ثقة محددة.

Automated Playbook Types

أنواع دفاتر العمل المؤتمتة

  • Endpoint Containment: Quarantine compromised endpoints via EDR API to prevent lateral movement while preserving forensic telemetry
  • احتواء نقطة النهاية: عزل نقاط النهاية المخترقة عبر واجهة EDR لمنع الانتشار مع الحفاظ على بيانات التتبع
  • Network Blocking: Push dynamic block lists to perimeter firewalls to sever active Command & Control channels
  • حظر شبكي: دفع قوائم الحظر الديناميكية للجدران النارية لقطع قنوات القيادة والتحكم النشطة
  • Account Suspension: Revoke active sessions and disable accounts exhibiting anomalous credential behavior
  • تعليق الحساب: إلغاء الجلسات النشطة وتعطيل الحسابات التي تُظهر سلوكاً غير طبيعي في بيانات الاعتماد
  • Malicious Content Purge: Identify and remove malicious messages enterprise-wide via email platform API
  • تطهير المحتوى الخبيث: تحديد وإزالة الرسائل الخبيثة على مستوى المؤسسة عبر واجهة منصة البريد الإلكتروني
