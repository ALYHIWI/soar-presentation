Implementation Technology Stack & Simulation Testbed

حزمة التقنيات المستخدمة وبيئة المحاكاة الاختبارية

Core Backend

الخادم ومحرك المعالجة

Python 3.11+, FastAPI for high-concurrency async endpoints, Celery / Redis for distributed queue management.

بايثون مع FastAPI لمعالجة متزامنة فائقة السرعة، وطوابير Redis لتوزيع المهام.

Machine Learning

الذكاء الاصطناعي

Scikit-Learn (Random Forest), PyTorch (DNN sequence models), Stable-Baselines3 (SAC reinforcement agent).

مكتبات Scikit-Learn و PyTorch و Stable-Baselines3 لتدريب نماذج الفرز والتعلم المعزز.

Data & Telemetry

البيانات والسجلات

Elasticsearch / OpenSearch cluster for fast indexing, PostgreSQL for case dossier storage and configuration.

محرك Elasticsearch لفهرسة السجلات بسرعة وبنك بيانات PostgreSQL لحفظ ملفات القضايا.

SOC Sensors & Testbed

الحساسات والمحاكاة

Wazuh SIEM/EDR, Suricata IDS, Atomic Red Team framework for adversary simulation, Docker containerized services.

منصة Wazuh وحساسات Suricata مع محاكاة هجمات Atomic Red Team ضمن حاويات Docker.

Adversary Mapping: All simulated attack vectors and detection rules are strictly aligned with the MITRE ATT&CK Enterprise Framework (T1059, T1078, T1486).

ربط التهديدات: جميع سيناريوهات الهجمات وقواعد الكشف متوافقة بدقة مع إطار MITRE ATT&CK العالمي.
