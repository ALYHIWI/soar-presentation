## 🌟 Features & Highlights | مميزات العرض التقديمي

- **25 Academic Bilingual Slides (الشرائح الـ 25 المعتمدة)**: تغطية شاملة ودقيقة للفصول 1 و 2 و 3 طبقاً لوثيقة المشروع ودليل العرض.
- **Bilingual Switcher (ثنائي اللغة)**: التبديل اللحظي بنقرة زر واحدة بين العربية (RTL) والإنجليزية (LTR).
- **Control Center (مركز التحكم الشامل)**:
  - 🌌 **4 Dynamic Canvas Backgrounds**: (Neural AI Mesh, Quantum Waves, Cyber Matrix, Space Warp).
  - 🎬 **4 Slide Animation Styles**: (Cascade Wave, 3D Flip Cube, Cyber Zoom, Soft Dissolve) مع دوران ثابت بدون أي سكرول أفقي.
  - 👑 **10 Royal Luxury Color Palettes**: تدرجات لونية ملكية فاخرة (Imperial Gold, Sultanate Emerald, Royal Sapphire, Monarch Violet, Crimson Ruby, Rose Gold, Nordic Aurora, Titanium Stealth, Antique Bronze, Quantum Matrix).
  - ⏱️ **Presentation Timer**: مؤقت عد تنازلي تفاعلي (15-20 دقيقة) مع إشارات تنبيه لونية.
  - ✏️ **Live In-Place Content Editor**: إمكانية تعديل أي نص في العرض مباشرة وحفظه محلياً في المتصفح (`LocalStorage`).
- **Zero Horizontal Scrollbar**: إزالة تامة لأي سكرول أفقي أو اهتزاز أثناء التنقل أو تفعيل الـ 3D.
- **GitHub Pages Ready**: جاهز للنشر المباشر عبر GitHub Pages ليعمل أونلاين لأعضاء الفريق والمشرف دون الحاجة لأي تثبيت.

## 🚀 Quick Start | التشغيل السريع

### 1. Local Development Server
```bash
# Clone the repository
git clone https://github.com/<username>/<repo-name>.git
cd SOAR

# Start local server
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. Direct Browser Opening
يمكنك أيضاً فتح ملف العرض مباشرة في أي متصفح حديث بالنقر المزدوج على:
`presentation/index.html`

### 3. Verify Slide Integrity
```bash
python verify_presentation.py
```

## ⌨️ Keyboard Shortcuts | اختصارات لوحة المفاتيح

| المفتاح | الوظيفة | Function |
|---|---|---|
| `→` / `Space` | الشريحة التالية | Next Slide |
| `←` | الشريحة السابقة | Previous Slide |
| `L` | تبديل اللغة (عربي / English) | Language Toggle |
| `C` | فتح / إغلاق مركز التحكم | Control Center Drawer |
| `F` | ملء الشاشة | Fullscreen Toggle |
| `E` | وضع التحرير المباشر | Live In-Place Editor |
| `Home` / `End` | الشريحة الأولى / الأخيرة | First / Last Slide |
